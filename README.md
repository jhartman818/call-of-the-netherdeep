# call-of-the-netherdeep

This repo contains character notes, session notes, and resources for my participation in a Call of the Netherdeep D&D campaign.

I am not familiar with the campaign (yet), but I expect to include session notes as it progresses, so consider this a spoiler alert.

This repo also contains character information and plans that might spoil surprises for other players. It is intended to be shared with the DM, not the rest of the party.
