

## Theme
*Identity/Value*.  This character's underlying theme is around identity and value.  It's centered on being a tool that was created for a purpose and then abandoned, and what that tool does afterwards.  How does it find value in itself?

## Surface Demeanor
Very literal, but with dry military humor.  Humor is indistinguishable from actual belief.  All business when combat begins.  As lazy as the commanding officer allows otherwise.

## Backstory Overview
A warforged created (or found and adapted, or whatever) and assigned the purpose of being the mobile artillery unit in an army, embedded with the soldiers.  Basically grew up learning what the soldiers would teach him, for example:
* Actual survival skills
* "that firebolt spell of yours would work better if you did finger guns afterwards"
* Actual combat tactics
* "always refer to casting Fireball as 'serving breakfast' so that the enemy doesn't know what's coming."
