# House Rules

Rules and procedures recorded during [Session 0](<../Session-Notes/Session 0.md>). This includes standard options selected for the campaign, not only changes to the published rules.

## Character Creation and Advancement

- Standard array.
- Milestone leveling.
- Fixed HP.
- Alignment determined by actions.

## Combat Rolls

- Natural 20: double the damage dice. In D&D Beyond, right-click and select critical.
- Natural 1: could hurt us or someone else; usually not full damage.

## Skill Checks

- Only one skill check attempt.
- Others can "assist," granting advantage.
- Possibly a group roll instead.

## Resting

- Can only rest when it is safe.
- Think about being equipped.
